⚡ ClueShift Cyber Clue Puzzle & Arcade

Full-Stack Clue Puzzle & Gaming Platform built with Laravel 11, React 19, Three.js 3D, and Web Audio API. Ready for CodeCanyon, SaaS, or Client Deployment.

📦 Product Overview

ClueShift is a high-engagement, modern clue puzzle and gaming platform featuring 5 unique game modes (5-Clue Word Puzzle, 1v1 PvP Brain Duel, Memory Speed Training, Knowledge Challenge, and Daily Mini Games), an interactive Three.js 3D background, Web Audio SFX sound engine, Daily Rewards Spin Wheel, In-Game Coin Store, and an Admin Panel with CSV bulk imports, visual analytics, and AI question generation.

🎮 5 Diverse Game Modes 5-Clue Core Levels, 1v1 Duel with Room Codes, Brain Training, Knowledge Challenge & Daily Mini Games.
🔊 Web Audio API Synthesizer Built-in synthesizer with zero external audio assets to 404. Chimes, buzzers, victory fanfare & ambient lo-fi synth.
🎁 7-Day Streak & Lucky Spin Wheel Daily retention loop with login rewards and an interactive HTML5 canvas prize wheel.
📥 Bulk CSV Import & Export Add 1000+ questions in 1-click via CSV spreadsheet with sample template download.
🤖 AI Question Generator Generate rich 5-clue trivia questions by entering any topic inside the Admin Panel.
💰 Monetization Ready Google AdSense banners, 5-second Rewarded Video Ads, and Virtual Coin/Perk Shop.

🚀 5-Minute Setup & Installation

1. Backend Setup (Laravel 11)

cd brainbuzz-backend
composer install
cp .env.example .env
php artisan key:generate

# Configure your database in .env:
# DB_CONNECTION=mysql
# DB_HOST=127.0.0.1
# DB_PORT=3306
# DB_DATABASE=brainbuzz
# DB_USERNAME=root
# DB_PASSWORD=

php artisan migrate --seed
php artisan serve --port=8001

2. Frontend Setup (React / Vite)

cd brainbuzz-frontend
npm install
npm run dev

💰 Monetization & Ad Placement

ClueShift is designed to generate revenue through multiple monetization streams:

  • Google AdSense Banners: Navigate to /admin/settings, paste your Publisher ID (ca-pub-XXXXXXXXXXXXXXXX) and toggle Ads ON.
  • Rewarded Video Ads: Players watch a 5-second video to earn +100 Coins or +1 Lifeline, maximizing eCPM revenue.
  • Virtual Coin Shop: Packages ranging from $0.99 to $14.99 (VIP Lifetime Pass). Ready to connect to Stripe or Razorpay.

📞 Commercial Support & Customization

ClueShift is fully modular and cleanly documented. For custom white-label branding, translations, or payment gateway connections, all styles and components are centralized in brainbuzz-frontend/src and brainbuzz-backend/app/Http/Controllers/Api.
